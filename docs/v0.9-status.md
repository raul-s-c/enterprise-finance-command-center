# v0.9 Release Status

Version 0.9 adds a frozen Annual Budget and full-year planning layer.

Validated before merge:

- 20/20 tests passed
- 36 rolling actual months
- 18 forecast months
- 59,681 operating records
- 526,059 journal lines
- 18,414 forecast records
- full GitHub Actions build completed with `validation_passed=True`

New capabilities:

- prior-year budget approval vintage
- no-hindsight budget construction
- driver-based commercial planning
- cost-center planning for zero-revenue factories
- monthly Budget phasing
- YTD Actual vs Budget
- FY Budget vs Latest Outlook
- FY outlook reconstruction at FC-1, FC-3 and FC-6
- depreciation-aware forecast EBIT
- entity/division plan bridge
- Plan & Forecast CFO view

New release controls:

- budget source period <= budget vintage
- 12 budget months per entity/division
- no duplicate budget rows
- frozen-budget reconstruction gap <= EUR 0.02
- current-year Budget present
- FY planning bridge present

The release keeps Annual Budget, rolling Forecast and Actuals as separate management objects rather than collapsing them into a single synthetic series.
