# v0.17 Release Status

Management Action Lifecycle and Close History release candidate.

Release scope:

- persistent action cycles across monthly closes
- Open, In Progress, Closed and Cancelled statuses
- owner, opening, last-seen, due, close and cancellation dates
- age, carry-forward and occurrence counts
- overdue detection and management/executive escalation
- dated closure or cancellation evidence
- monthly action and performance-review history
- deterministic action change log
- dashboard lifecycle trends and overdue register
- backward-compatible migration of v0.16 action artifacts

Lifecycle controls cover unique IDs and active keys, current-trigger coverage, review evidence, terminal evidence, overdue escalation, complete snapshots, history uniqueness, change referential integrity and status-count reconciliation.

Version 0.17 retains all controls introduced through v0.16. Final production counts and status are written by the production close.
