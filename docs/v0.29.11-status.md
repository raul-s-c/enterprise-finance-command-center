# v0.29.11 status

## Scope

On narrow screens, the Working Capital evidence table contains more columns than fit in the available width. The table could be horizontally scrolled, but the control gave no visible cue, focus target or keyboard navigation for the clipped columns.

## Delivered

- Makes all contribution evidence tables focusable labeled regions, not only cash lineage evidence.
- Adds left/right arrow-key scrolling to the horizontally overflowing evidence area.
- Shows a short visual and accessible instruction only while columns are clipped; a resize observer updates the hint when responsive panels are shown or resized.
- Extends the mobile regression to verify overflow guidance, keyboard navigation and no document-level horizontal overflow.

## Financial impact

Presentation and navigation only. Published amounts, source records, calculations, accounting policies, reconciliations and close controls are unchanged.

## Validation

The focused mobile browser regression, complete UI suite, standard test suite and finance close must pass before merge and deployment.
