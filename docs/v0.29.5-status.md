# v0.29.5 status

## Scope

At 901–1500 CSS pixels, the cockpit workspaces previously required the user to switch among three analysis-focus tabs to see the main driver chart, linked formula/flow and contribution detail. This hid the formula at the same time the key trend was on screen.

## Delivered

- Keeps the primary driver chart and linked formula or forecast flow side by side in Cash Flow, Treasury, Balance Sheet and Planning cockpits.
- Opens Contribution & detail as a full-width focus view with an explicit path back to Trend & drivers.
- Preserves the existing single-focus layout below 901px for narrow mobile screens.
- Adds a Playwright regression at 1040×720 for all four cockpits, checking panel bounds, internal overflow, detail focus switching and viewport fit.
- Attaches a screenshot for each cockpit.

## Financial impact

Presentation and navigation only. No ledger values, calculations, accounting policies, reconciliation tolerances or close controls change.

## Validation

The focused browser regression and the complete release workflow must pass before merge and production deployment.
