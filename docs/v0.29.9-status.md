# v0.29.9 status

## Scope

The financial KPI strip on mobile screens showed a native horizontal scrollbar and offered no clear snap behavior when readers moved between measures. The cards remained reachable, but the scrollbar chrome competed with the report and keyboard focus did not have a documented regression check.

## Delivered

- Hides only the scrollbar track on financial KPI carousels below 901 CSS pixels; touch, trackpad and keyboard scrolling remain available.
- Keeps snap alignment at each KPI card and contains horizontal overscroll within the strip.
- Adds a browser regression for the Cash Flow cockpit proving that all five KPIs remain in the DOM, the last card is reachable by keyboard focus and scrolls fully into view, and page width does not overflow.
- Updates asset cache keys to v0.29.9 so deployed clients load the release styles.

## Financial impact

Presentation and interaction only. KPI values, calculations, accounting policies, reconciliations and close controls are unchanged.

## Validation

The focused mobile KPI regression, full UI suite, standard test suite, finance close and consecutive-close continuity regression must pass before merge and deployment.
