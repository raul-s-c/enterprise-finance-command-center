# v0.18 Release Status

Management Action Execution and Benefits Realization release.

Release scope:

- one controlled execution plan per persistent action cycle
- approval, effective, target and benefit-end dates
- deterministic price, volume, variable-cost and non-people-OPEX interventions
- post-approval effective dates and three-month benefit ramp
- governance-only treatment for non-monetary actions
- causal action effects in operating transactions and the balanced ledger
- integrated Base, Upside and Downside forecast impact
- directional non-additive trigger improvement
- additive actual and forecast portfolio bridges
- dashboard execution portfolio and benefits evidence

Version 0.18 retains every accounting, consolidation, Working Capital, Treasury, Budget, forecast, workforce, FX, performance-review and lifecycle control introduced through v0.17.
