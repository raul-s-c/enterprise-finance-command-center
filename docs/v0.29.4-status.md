# v0.29.4 status

The release repairs the graphical P&L in the intermediate laptop-width band. The desktop shell reserves space for the report navigation, which left the five-column income statement wider than its usable content between 901 and 1100 CSS pixels.

## Delivered

- Uses compact responsive column tracks on 901–1100px canvases so the final comparison columns remain visible without horizontal clipping.
- Keeps the existing two-mode compact presentation at 900px and below.
- Adds a Playwright regression at 1100×720, 1040×720 and 901×720. It checks all five heading columns and every row stay within the visible statement panel, and attaches a screenshot at 1040×720.
