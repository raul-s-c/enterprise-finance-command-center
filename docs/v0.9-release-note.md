# v0.9 Release Note

Version 0.9 promotes Annual Budget and full-year planning to first-class finance objects.

Validated in GitHub Actions before merge:

- 20/20 tests passed
- 36 actual months
- 18 forecast months
- 59,681 operating rows
- 526,059 journal rows
- 18,414 forecast rows
- full build completed with `validation_passed=True`

The release introduces a frozen prior-year Budget vintage, no-hindsight controls, commercial and cost-center planning models, YTD Actual vs Budget, FY Latest Outlook, FC-1 / FC-3 / FC-6 outlook reconstruction and depreciation-aware forecast EBIT.
