# v0.15 Release Status

Workforce Cost Planning and Multi-Currency FX release candidate.

Release scope:

- 36 actual months
- 18 rolling operating forecast months
- 12-month Base / Upside / Downside liquidity and three-statement forecast
- Month x Entity x Division x Function workforce schedules
- workforce-driven payroll, recruitment cost and forecast OPEX
- functional-currency journals for EUR, CZK, CNY, USD and JPY
- local trial balances and EUR group translation
- historical equity translation and explicit CTA / OCI
- reported and constant-currency Revenue and EBIT

Workforce controls:

- FTE roll-forward
- non-negative workforce values
- personnel-cost allocation
- payroll journal reconciliation
- no payroll postings to Trade AP
- workforce-driven forecast OPEX identity
- payroll cash identity

FX controls:

- functional-currency journals balance after local rounding
- EUR to local to EUR round-trip remains within materiality
- translated Assets equal Liabilities plus historical Equity plus CTA
- functional-currency journal, translation schedule and constant-currency analysis exist

Version 0.15 retains all controls introduced through v0.13, including actual accounting, intercompany, Working Capital, asset quality, customer funding, Treasury, Budget, rolling forecast, forward liquidity and integrated three-statement forecasting.

Final validated counts and control status are written by the production close.
