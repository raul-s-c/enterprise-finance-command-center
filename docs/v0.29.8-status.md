# v0.29.8 status

## Scope

The mobile P&L previously had both a report-level scrollbar and an inner statement scrollbar. The accounting note could sit below the visible report area, making the final rows and caveat harder to discover. The Executive overview also clipped the management-priority rail at standard desktop and short laptop heights.

## Delivered

- Uses the report canvas as the only vertical scroller at mobile and tablet widths.
- Keeps all ten statement lines, the Values / Δ PY switch and the accounting note in the same reading flow.
- Preserves the internal statement canvas on wider laptop layouts, where the complete comparison is designed to fit the viewport.
- Fits all three Executive management priorities within the one-screen layout at 1024×720 and 1440×900 while retaining trigger, owner, due date and status.
- Reuses the validated close artifact for visual regressions so the dashboard is not rebuilt a second time in the same workflow.
- Adds responsive regressions at 320, 390, 600, 700 and 768 CSS pixels, plus Executive layout checks from 1024×720 through 1920×820.

## Financial impact

Presentation, navigation and CI efficiency only. Ledger values, statement calculations, accounting policies, reconciliation tolerances and close controls are unchanged.

## Validation

The mobile single-scroll regression, Executive one-screen regression, full zoom/reflow audit, finance close and continuity regression must pass before merge and deployment.
