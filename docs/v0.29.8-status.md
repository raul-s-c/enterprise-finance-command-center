# v0.29.8 status

## Scope

The mobile P&L previously had both a report-level scrollbar and an inner statement scrollbar. The accounting note could sit below the visible report area, making the final rows and caveat harder to discover.

## Delivered

- Uses the report canvas as the only vertical scroller at mobile and tablet widths.
- Keeps all ten statement lines, the Values / Δ PY switch and the accounting note in the same reading flow.
- Preserves the internal statement canvas on wider laptop layouts, where the complete comparison is designed to fit the viewport.
- Adds responsive regressions at 320, 390, 600, 700 and 768 CSS pixels.

## Financial impact

Presentation and navigation only. Ledger values, statement calculations, accounting policies, reconciliation tolerances and close controls are unchanged.

## Validation

The mobile single-scroll regression, full zoom/reflow audit and production release workflow must pass before merge and deployment.
