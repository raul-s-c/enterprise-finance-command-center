# v0.29.12 status

## Scope

The interactive monthly close walkthrough existed under Close & Controls, but contextual Help did not give a first-time reader an obvious route into it. Returning to the tour could also leave it on a previously selected stage despite the entry point saying “Start”.

## Delivered

- Add a prominent, responsive “Start the close tour” callout to Help on every report.
- Route the callout directly to the eight-stage close walkthrough.
- Always begin at Drivers from this entry point, including when reopening the tour after visiting report evidence.
- Add a Playwright regression for desktop and mobile that opens Help, traverses into real report evidence, and re-enters the tour at the first stage.

## Financial impact

Navigation and presentation only. Published values, formulas, accounting policies, reconciliations and control tolerances are unchanged.

## Validation

The focused browser regression, full UI suite, standard test suite and finance close must pass before merge and deployment.
