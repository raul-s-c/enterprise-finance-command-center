# v0.29.10 status

## Scope

On mobile and tablet contribution pages, changing the breakdown dimension rebuilt the contribution workspace but removed its focus navigation. Responsive styling then hid every analytical panel, leaving the financial summary visible while the contribution, value-flow, evidence and detail views were unavailable.

## Delivered

- Re-mounts the contribution focus navigation after each in-place contribution redraw.
- Makes the focus navigation mount idempotent so the first render does not create duplicate controls.
- Preserves the currently selected focus panel across dimension changes.
- Adds a mobile browser regression that changes the Working Capital dimension, checks that contribution rows remain visible, opens underlying records, and confirms no horizontal page overflow.

## Financial impact

Presentation and interaction only. Published amounts, source records, calculations, accounting policies, reconciliations and close controls are unchanged.

## Validation

The focused mobile interaction regression, full UI suite, standard test suite and finance close must pass before merge and deployment.
